# اسکرپر بلد و نشان

افزونه کروم برای استخراج اطلاعات کسب‌وکارها از سایت بلد.ir و نشان.ir و ذخیره در فایل CSV.

## وضعیت پروژه

این پروژه در حال توسعه است و مشکلات زیادی دارد. فعلاً برای استفاده عملی توصیه نمی‌شود. اگر می‌خواهید کمک کنید، خوشحال می‌شوم.

مشکلات اصلی:
- بعد از دانلود CSV مرورگر کرش می‌کند
- گاهی خطای HTTP 418 می‌دهد
- بعضی وقت‌ها اطلاعات کامل استخراج نمی‌شود

لیست کامل مشکلات در فایل ISSUES.md هست.

## نصب

1. پروژه رو دانلود کنید
2. Chrome رو باز کنید و به `chrome://extensions/` برید
3. "Developer mode" رو فعال کنید
4. "Load unpacked" رو بزنید
5. پوشه پروژه رو انتخاب کنید

## استفاده

1. به balad.ir برید
2. یک جستجو انجام بدید (مثلاً "رستوران تهران")
3. روی آیکون افزونه کلیک کنید
4. شهر یا استان رو وارد کنید
5. فیلترها رو تنظیم کنید (اختیاری)
6. "شروع اسکرپینگ" رو بزنید
7. صبر کنید تا تمام بشه
8. "دانلود CSV" رو بزنید

**هشدار:** دکمه دانلود ممکنه باعث کرش مرورگر بشه. با احتیاط استفاده کنید.

## مشکلات شناخته شده

پروژه مشکلات زیادی داره که هنوز حل نشدن. مهم‌ترین‌هاش:

1. **کرش بعد از دانلود CSV** - وقتی روی دکمه دانلود می‌زنید، مرورگر کرش می‌کنه. چند تا راه حل امتحان کردم ولی هیچکدوم کار نکرد.

2. **خطای HTTP 418** - بعضی وقت‌ها سرور بلد خطای 418 می‌ده و استخراج متوقف می‌شه. تاخیر بین درخواست‌ها رو زیاد کردم ولی بازم گاهی پیش میاد.

3. **اتصال قطع می‌شه** - گاهی ارتباط بین content script و background script قطع می‌شه و اطلاعات تماس (تلفن، ایمیل) استخراج نمی‌شه.

4. **اطلاعات ناقص** - بعضی وقت‌ها اطلاعات کامل نیست. مثلاً فقط مختصات میاد و آدرس کامل نمیاد.

لیست کامل مشکلات و جزئیات بیشتر توی ISSUES.md هست.

## توسعه

اگر می‌خواهید کمک کنید:

1. ISSUES.md رو بخونید و ببینید چه مشکلاتی هست
2. پروژه رو fork کنید
3. یک branch جدید بسازید
4. تغییراتتون رو اعمال کنید
5. تست کنید (فعلاً تست دستی لازمه)
6. Pull Request بفرستید

راهنمای کامل‌تر توی CONTRIBUTING.md هست.

## نکات فنی

- Selectorهای CSS ممکنه نیاز به به‌روزرسانی داشته باشن. اگر ساختار DOM سایت بلد تغییر کنه، باید selectorها رو عوض کنید.
- بین هر صفحه 2 تا 5 ثانیه تاخیر هست تا از بلاک شدن جلوگیری بشه.
- فایل CSV با UTF-8 BOM ذخیره می‌شه تا کاراکترهای فارسی درست نمایش داده بشن.

## محدودیت‌ها

- فقط روی Chrome/Chromium کار می‌کنه
- اگر ساختار سایت بلد تغییر کنه، باید selectorها رو به‌روز کنید
- تست خودکار نداره، همه چیز دستی تست می‌شه
- با داده‌های خیلی بزرگ ممکنه مشکل داشته باشه
